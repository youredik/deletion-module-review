## Что здесь лежит

Исходники вашего модуля я сюда не выкладывал — это часть внутренней библиотеки, ей не
место в открытом репозитории. В ревью цитируются только отдельные строки по делу.

Чтобы запустить тесты, положите модуль в `src/Shared/Deletion/`:

```bash
composer install
cp -r /путь/к/Deletion src/Shared/Deletion
./vendor/bin/phpunit
```

Класса `Shared\Persistence\GenericReadRepository` в архиве не было, а `DeletionService`
требует его в конструкторе — поэтому рядом лежит заглушка, собранная по вызовам. Тестовый
двойник наследуется от неё: подменить зависимость обычным способом нельзя, потому что в
конструкторе указан конкретный класс, а не интерфейс.

Смотрел на PHP 8.5.6, PHPUnit 13.2.6, Doctrine ORM 2.19 и 3.6.7 — часть поведения от
версии ORM зависит, это отмечено в ревью.
